Proofs

This file contains complete proofs of four statements. Each proof is written as a sequence of steps. Every step is justified either by a lemma proved in this file, or by a standard result that is named at the point of use. The standard facts we allow ourselves are:

  • Division algorithm. For every integer a and every positive integer d there exist unique integers q, r with a = dq + r and 0 <= r < d. The remainder r is what we mean by "a mod d", and we write a ≡ b (mod m) for m | (a − b).
  • Existence and uniqueness of prime factorisations. Every integer greater than 1 is a product of primes, uniquely up to the order of the factors.
  • Euclid's lemma. If a prime p divides a product xy, then p | x or p | y.
  • Arithmetic of congruences. If a ≡ b (mod m) and c ≡ d (mod m), then a + c ≡ b + d (mod m) and ac ≡ bd (mod m). These follow by writing a = b + ms, c = d + mt and expanding.
  • Square roots in the reals. Every positive real number has a unique positive square root (this is a consequence of the completeness of R). The map x ↦ x^2 is strictly increasing on [0, ∞): if 0 <= x < y then y^2 − x^2 = (y − x)(y + x) > 0.
  • Binomial expansions. (x + y)^2 = x^2 + 2xy + y^2 and (x + y)^3 = x^3 + 3x^2 y + 3xy^2 + y^3, both obtained by repeated use of the distributive, commutative and associative laws.
  • Maximum principle for finite sets. Every non-empty finite set of integers has a largest element.

1. There are infinitely many primes congruent to 3 modulo 4

We first isolate three small facts.

Lemma 1.1. Every integer m > 1 has a prime divisor.

Proof. We argue by strong induction on m. For m = 2: 2 is prime and divides itself. Now let m > 2 and suppose the claim holds for all integers strictly between 1 and m. If m is prime, then m | m and we are done. If m is not prime, then by definition of "composite" there exist integers a, b with m = ab and 1 < a < m. By the induction hypothesis applied to a, there is a prime p with p | a, say a = pt. Then m = ab = p(tb), so p | m. ∎

Lemma 1.2. Every odd prime p satisfies p ≡ 1 (mod 4) or p ≡ 3 (mod 4).

Proof. By the division algorithm with divisor 4, p = 4q + r with a unique r ∈ {0, 1, 2, 3}. If r = 0, then p = 4q = 2 · (2q), so 2 | p; since p is prime, its only positive divisors are 1 and p, so p = 2, contradicting that p is odd. If r = 2, then p = 4q + 2 = 2(2q + 1), and the same argument gives p = 2, again a contradiction. Hence r ∈ {1, 3}. ∎

Lemma 1.3. A product of integers each congruent to 1 modulo 4 is itself congruent to 1 modulo 4.

Proof. First the two-factor case: if a = 4s + 1 and b = 4t + 1, then ab = (4s+1)(4t+1) = 16st + 4s + 4t + 1 = 4(4st + s + t) + 1 ≡ 1 (mod 4). The general statement follows by induction on the number of factors: a product of one factor is congruent to 1 by assumption, and a product of k + 1 factors is a product of k factors (congruent to 1 by the induction hypothesis) times one more factor congruent to 1, which by the two-factor case is congruent to 1. ∎

Theorem 1.4. There are infinitely many primes congruent to 3 modulo 4.

Proof. Suppose, for a contradiction, that there are only finitely many, and list them all as p_1, ..., p_k.

  1. The list is non-empty: 3 is prime and 3 = 4 · 0 + 3, so 3 ≡ 3 (mod 4); hence k >= 1 and p_1 p_2 ⋯ p_k >= 3.
  2. Define N = 4 p_1 p_2 ⋯ p_k − 1. Since the product is at least 3, N >= 4 · 3 − 1 = 11 > 1.
  3. N ≡ 3 (mod 4): indeed N = 4(p_1 ⋯ p_k − 1) + 3, and p_1 ⋯ p_k − 1 >= 0, so by the division algorithm the remainder of N upon division by 4 is 3.
  4. N is odd: N = 2(2 p_1 ⋯ p_k − 1) + 1 is one more than an even number.
  5. By Lemma 1.1 (applied repeatedly, i.e. by existence of prime factorisations), N = q_1 q_2 ⋯ q_t for some primes q_1, ..., q_t, with t >= 1 because N > 1.
  6. Each q_j is odd: q_j | N, and if q_j = 2 then N = q_j · (N / q_j) would be even, contradicting step 4.
  7. By Lemma 1.2, each q_j ≡ 1 (mod 4) or q_j ≡ 3 (mod 4).
  8. Some q_j ≡ 3 (mod 4). For if every q_j ≡ 1 (mod 4), then by Lemma 1.3 applied to the product q_1 ⋯ q_t we would have N ≡ 1 (mod 4), contradicting step 3: by uniqueness of the remainder in the division algorithm, N cannot have both remainder 1 and remainder 3 upon division by 4.
  9. Fix an index j with q := q_j ≡ 3 (mod 4). By the exhaustiveness assumption, q is one of p_1, ..., p_k. Then q divides the product p_1 ⋯ p_k (that product is q times the product of the remaining p_i's), so q | 4 p_1 ⋯ p_k. But 4 p_1 ⋯ p_k = N + 1, and also q | N (step 5). Hence q | (N + 1) − N = 1.
  10. No prime divides 1: if q | 1, then 1 = qm for some positive integer m, so q <= qm = 1, contradicting q >= 2.

Steps 9 and 10 contradict each other. Therefore the assumption that the list p_1, ..., p_k was complete is false, and there are infinitely many primes congruent to 3 modulo 4. ∎

2. The number sqrt(2) + sqrt(3) is irrational

A real number is rational if it equals a / b for integers a, b with b ≠ 0; otherwise it is irrational.

Lemma 2.1 (rational root test, monic case). Let n >= 1 and let f(x) = x^n + c_{n−1} x^{n−1} + ⋯ + c_1 x + c_0 have integer coefficients. If the rational number r = a / b, written in lowest terms with b > 0 and gcd(a, b) = 1, is a root of f, then b = 1 and a | c_0. In particular every rational root of a monic integer polynomial is an integer dividing the constant term.

Proof. Assume f(a/b) = 0. Multiply the equation by b^n (legal since b >= 1):

a^n + c_{n−1} a^{n−1} b + c_{n−2} a^{n−2} b^2 + ⋯ + c_1 a b^{n−1} + c_0 b^n = 0.

Every term except the first contains a factor b, so

a^n = −b · (c_{n−1} a^{n−1} + c_{n−2} a^{n−2} b + ⋯ + c_0 b^{n−1}),

and the bracket is an integer. Hence b | a^n. We claim gcd(a^n, b) = 1: if a prime ℓ divided both, then ℓ | a^n, so by Euclid's lemma (applied n times) ℓ | a; but then ℓ divides both a and b, contradicting gcd(a, b) = 1. Since b | a^n and gcd(a^n, b) = 1, b has no prime divisor, so b = 1.

With b = 1 the displayed identity becomes a^n + c_{n−1} a^{n−1} + ⋯ + c_1 a + c_0 = 0, so

c_0 = −a · (a^{n−1} + c_{n−1} a^{n−2} + ⋯ + c_1),

where the bracket is an integer; hence a | c_0. ∎

Lemma 2.2. sqrt(2) · sqrt(3) = sqrt(6).

Proof. Both numbers are positive. Their squares are equal: (√2 · √3)^2 = (√2)^2 (√3)^2 = 2 · 3 = 6 (using (xy)^2 = x^2 y^2, which is commutativity and associativity of multiplication), and (√6)^2 = 6 by definition of the square root. If two positive reals x, y satisfy x^2 = y^2, then 0 = x^2 − y^2 = (x − y)(x + y); since x + y > 0 we must have x − y = 0, i.e. x = y. Applying this to x = √2 · √3 and y = √6 gives the claim. ∎

Proposition 2.3. The number α = √2 + √3 is a root of the polynomial f(x) = x^4 − 10x^2 + 1.

Proof. Compute, using the binomial expansion of (x + y)^2 and Lemma 2.2:

α^2 = (√2 + √3)^2 = (√2)^2 + 2·√2·√3 + (√3)^2 = 2 + 2√6 + 3 = 5 + 2√6.

Squaring once more:

α^4 = (5 + 2√6)^2 = 25 + 2·5·2√6 + (2√6)^2 = 25 + 20√6 + 4·6 = 49 + 20√6,

where (2√6)^2 = 4 · (√6)^2 = 4 · 6 = 24. Also 10α^2 = 50 + 20√6. Therefore

f(α) = α^4 − 10α^2 + 1 = (49 + 20√6) − (50 + 20√6) + 1 = (49 − 50 + 1) + (20 − 20)·√6 = 0.

∎

Theorem 2.4. √2 + √3 is irrational.

Proof. Let α = √2 + √3.

  1. α > 1. First, √2 > 1: if √2 <= 1, then since both sides are non-negative, monotonicity of squaring on [0, ∞) would give 2 = (√2)^2 <= 1^2 = 1, a contradiction. Second, √3 > 0: √3 >= 0 by definition, and √3 = 0 would give 3 = (√3)^2 = 0. Adding: α = √2 + √3 > 1 + 0 = 1.
  2. Suppose for a contradiction that α is rational, and write α = a / b in lowest terms with b > 0.
  3. By Proposition 2.3, α is a root of the monic polynomial x^4 − 10x^2 + 1 with integer coefficients. By Lemma 2.1, b = 1 and a | 1. The only integers dividing 1 are 1 and −1, so α = a ∈ {1, −1}.
  4. But step 1 gives α > 1, so α ≠ 1 and α ≠ −1, a contradiction.

Hence α is irrational. ∎

Remark. The proof actually shows more: the argument of Lemma 2.1 applied to any polynomial of degree at most 3 with integer coefficients that vanished at α would force α to be a root of x^4 − 10x^2 + 1 as well, and one can check (as our script check.py does numerically, and as linear independence of 1, √2, √3, √6 over Q shows exactly) that no nonzero polynomial of degree below 4 with small integer coefficients vanishes at α. The polynomial x^4 − 10x^2 + 1 is in fact the minimal polynomial of α.

3. Every finite tournament has a Hamiltonian path

Definitions. A tournament T = (V, E) on a finite vertex set V is an orientation of the complete graph: for every unordered pair {u, v} of distinct vertices, exactly one of the directed edges u → v and v → u belongs to E. A directed path in T is a sequence of distinct vertices x_1, x_2, ..., x_m such that x_i → x_{i+1} belongs to E for every i = 1, ..., m − 1. A directed path is Hamiltonian if it contains every vertex of V exactly once, i.e. if m = |V| and {x_1, ..., x_m} = V.

Theorem 3.1. Every finite tournament on n >= 1 vertices has a Hamiltonian path.

Proof. By induction on n.

Base case n = 1. Let V = {v}. The one-term sequence (v) is a directed path: the condition "x_i → x_{i+1} for every i = 1, ..., 0" quantifies over an empty set of indices, so it holds. The sequence contains the single vertex exactly once, so it is Hamiltonian.

Inductive step. Let n >= 2, and assume that every tournament on n − 1 vertices has a Hamiltonian path. Let T = (V, E) be a tournament with |V| = n.

  1. V is non-empty (it has n >= 2 elements), so we may pick a vertex v ∈ V.
  2. Let V' = V \ {v} and let T' be the tournament obtained by deleting v and all edges touching v. T' is a tournament: for any pair {u, w} of distinct vertices of V', the pair is also a pair of vertices of T, where exactly one of u → w, w → u lies in E; that same unique edge lies in T'. Also |V'| = n − 1 >= 1.
  3. By the induction hypothesis, T' has a Hamiltonian path P : x_1 → x_2 → ⋯ → x_{n−1}. Thus {x_1, ..., x_{n−1}} = V', the x_i are pairwise distinct, and x_i → x_{i+1} ∈ E for all 1 <= i <= n − 2.
  4. We now insert v into this path. For each i, the pair {v, x_i} consists of two distinct vertices of T, so by the definition of a tournament exactly one of v → x_i and x_i → v holds. There are three cases.

Case 1: v → x_1. Then (v, x_1, x_2, ..., x_{n−1}) is a directed path: its consecutive pairs are (v, x_1), an edge by assumption, and (x_i, x_{i+1}), edges by step 3. Its vertices are pairwise distinct (v is not in V', and the x_i are distinct and exhaust V'), and there are n of them, so the path is Hamiltonian.

Case 2: x_{n−1} → v. The same argument with v placed at the end shows that (x_1, ..., x_{n−1}, v) is a Hamiltonian path.

Case 3: neither Case 1 nor Case 2 holds. By the "exactly one" property of step 4, failure of v → x_1 means x_1 → v, and failure of x_{n−1} → v means v → x_{n−1}. (Note this case cannot occur when n = 2: then x_1 = x_{n−1}, and x_1 → v together with v → x_{n−1} = x_1 would put both directions of the same pair in E, impossible.) Consider the set S = { i ∈ {1, ..., n−1} : x_i → v }. We have 1 ∈ S and n − 1 ∉ S, so S is non-empty and not the whole index set. By the maximum principle for finite sets, S has a largest element i. Since n − 1 ∉ S, this i satisfies i <= n − 2, so i + 1 <= n − 1 is a valid index. Because i + 1 > i = max S, i + 1 ∉ S, i.e. it is not the case that x_{i+1} → v; by the "exactly one" property again, v → x_{i+1}. By definition of S we also have x_i → v. Now form

(x_1, ..., x_i, v, x_{i+1}, ..., x_{n−1}).

Check the consecutive pairs one by one: (x_j, x_{j+1}) for j < i and for i + 1 <= j <= n − 2 are edges by step 3; (x_i, v) is an edge because x_i → v; (v, x_{i+1}) is an edge because v → x_{i+1}. The sequence has n pairwise distinct vertices and covers V' together with v, so it is a Hamiltonian path.

  1. The three cases are exhaustive: either v → x_1 (Case 1), or x_1 → v and then either x_{n−1} → v (Case 2) or v → x_{n−1} (Case 3). In every case we produced a Hamiltonian path of T.

By the principle of induction, every tournament on n >= 1 vertices has a Hamiltonian path. ∎

4. The sum of the first n odd cubes is n^2 (2n^2 − 1)

Theorem 4.1. For every integer n >= 1,

1^3 + 3^3 + 5^3 + ⋯ + (2n − 1)^3 = n^2 (2n^2 − 1).

Proof. Write S(n) for the claimed identity. We use induction on n.

Base case n = 1. The left side is the single term (2·1 − 1)^3 = 1^3 = 1. The right side is 1^2 · (2·1^2 − 1) = 1 · 1 = 1. The two sides agree, so S(1) holds.

Inductive step. Assume S(n) holds for some n >= 1; we prove S(n + 1), i.e.

1^3 + 3^3 + ⋯ + (2n − 1)^3 + (2n + 1)^3 = (n + 1)^2 ( 2(n + 1)^2 − 1 ).
  1. Split off the last term (the (n+1)-st odd number is 2(n+1) − 1 = 2n + 1):

Σ_{i=1}^{n+1} (2i − 1)^3 = [ Σ_{i=1}^{n} (2i − 1)^3 ] + (2n + 1)^3.

  1. Replace the bracket by the induction hypothesis:

Σ_{i=1}^{n+1} (2i − 1)^3 = n^2 (2n^2 − 1) + (2n + 1)^3.

  1. Expand the first summand by distributivity: n^2 (2n^2 − 1) = 2n^4 − n^2.
  2. Expand the second summand by the binomial theorem with x = 2n, y = 1: (2n + 1)^3 = (2n)^3 + 3(2n)^2 · 1 + 3(2n) · 1^2 + 1^3 = 8n^3 + 12n^2 + 6n + 1.
  3. Add the results of steps 3 and 4, collecting equal powers of n:

2n^4 − n^2 + 8n^3 + 12n^2 + 6n + 1 = 2n^4 + 8n^3 + 11n^2 + 6n + 1.

So the left side of S(n + 1) equals 2n^4 + 8n^3 + 11n^2 + 6n + 1. 6. Now expand the right side of S(n + 1). First (n + 1)^2 = n^2 + 2n + 1 and 2(n + 1)^2 − 1 = 2n^2 + 4n + 2 − 1 = 2n^2 + 4n + 1. Then, distributing the product factor by factor,

(n^2 + 2n + 1)(2n^2 + 4n + 1) = n^2(2n^2 + 4n + 1) + 2n(2n^2 + 4n + 1) + 1·(2n^2 + 4n + 1) = (2n^4 + 4n^3 + n^2) + (4n^3 + 8n^2 + 2n) + (2n^2 + 4n + 1) = 2n^4 + (4 + 4)n^3 + (1 + 8 + 2)n^2 + (2 + 4)n + 1 = 2n^4 + 8n^3 + 11n^2 + 6n + 1.

  1. The expressions in steps 5 and 6 are identical, so the left and right sides of S(n + 1) are equal, and S(n + 1) holds.

By the principle of induction, S(n) holds for every integer n >= 1. ∎

Remark (a direct derivation). Let T(m) = 1^3 + 2^3 + ⋯ + m^3 = (m(m + 1) / 2)^2 (the classical cube-sum identity, itself provable by induction exactly as above). The sum of the first n odd cubes is the sum of all cubes up to 2n minus the sum of the even cubes 2^3 + 4^3 + ⋯ + (2n)^3 = 8 · T(n). Hence

Σ_{i=1}^{n} (2i − 1)^3 = T(2n) − 8 T(n)
                       = (2n(2n + 1)/2)^2 − 8 (n(n + 1)/2)^2
                       = n^2 (2n + 1)^2 − 2 n^2 (n + 1)^2
                       = n^2 [ (4n^2 + 4n + 1) − (2n^2 + 4n + 2) ]
                       = n^2 (2n^2 − 1).

Each equality is an expansion verified by the distributive law, in the same style as steps 3–6 of the induction above.
