Four Proofs

This document contains complete, step-by-step proofs of four statements. A short list of standard facts used repeatedly is given first; every nontrivial step in the proofs cites either one of these facts, an earlier lemma in the same proof, or an explicit algebraic manipulation.

Conventions and standard facts

Throughout, Z denotes the integers and N the positive integers. We use the following standard facts, each of which is provable in an introductory number theory or discrete mathematics course.

  • (F1) Modular arithmetic. If a ≡ a' (mod m) and b ≡ b' (mod m), then a + b ≡ a' + b' (mod m) and ab ≡ a'b' (mod m). This follows by writing a = a' + mr, b = b' + ms: then a + b = (a' + b') + m(r + s) and ab = a'b' + m(rb' + sa' + mrs), both congruent to a' + b' and a'b' modulo m.
  • (F2) Divisibility. If d | x and d | y then d | (x − y), since x = dr, y = ds give x − y = d(r − s). No integer d with |d| > 1 divides 1.
  • (F3) Existence and uniqueness of prime factorization (Fundamental Theorem of Arithmetic). Every integer N > 1 can be written as a product of primes, and this product is unique up to reordering. We use uniqueness only in Lemma 2.1.
  • (F4) Well-ordering / maximum principle. Every nonempty finite set of integers has a largest element.
  • (F5) Principle of mathematical induction. If S(1) holds, and S(n) ⇒ S(n+1) for all n ≥ 1, then S(n) holds for all n ≥ 1.
  • (F6) The square root. For each real t > 0 there is a unique real s > 0 with s² = t, written √t. Uniqueness: if s² = u² = t with s, u > 0 then (s − u)(s + u) = 0 and s + u > 0, so s = u. Existence is a standard fact about the real numbers (completeness); we take it as known. Also, for s, u > 0, su is the unique positive number whose square is s²u², so √(s²u²) = su; in particular √2 · √3 is the positive number whose square is 2·3 = 6, so √2 · √3 = √6. Likewise, s > u > 0 implies √s > √u, because (√s − √u)(√s + √u) = s − u > 0 and √s + √u > 0 force √s − √u > 0.

Theorem 1. There are infinitely many primes congruent to 3 modulo 4.

We first record two lemmas.

Lemma 1.1. The product of any finite collection of integers each congruent to 1 modulo 4 is itself congruent to 1 modulo 4.

Proof. We argue by induction on the number k of factors. For k = 1 the claim is the assumption. For the induction step, let a ≡ 1 (mod 4) and, by the induction hypothesis, let the product of the first k factors satisfy P ≡ 1 (mod 4). By (F1), P·a ≡ 1·1 = 1 (mod 4). To see the underlying arithmetic concretely: P = 4r + 1 and a = 4s + 1 give P·a = (4r+1)(4s+1) = 16rs + 4r + 4s + 1 = 4(4rs + r + s) + 1 ≡ 1 (mod 4). By (F5), the claim holds for all k. ∎

Lemma 1.2. Let N be an integer with N ≡ 3 (mod 4). Then at least one prime divisor of N is congruent to 3 modulo 4.

Proof. First, N is odd: if N were even, N = 2m would give N ≡ 0 or 2 (mod 4) according as m is even or odd, contradicting N ≡ 3 (mod 4). By (F3), N has at least one prime factorization N = p₁p₂⋯p_k (with k ≥ 1, since N ≡ 3 (mod 4) forces N ≥ 3 > 1). Every prime dividing N is odd, because N is odd; every odd prime p satisfies p ≡ 1 (mod 4) or p ≡ 3 (mod 4), by the division algorithm applied to p and 4 (an odd prime is not divisible by 2, so its remainder mod 4 is not 0 or 2).

Suppose for contradiction that every pᵢ ≡ 1 (mod 4). Then Lemma 1.1 gives N = p₁⋯p_k ≡ 1 (mod 4), contradicting the hypothesis N ≡ 3 (mod 4). Hence some pᵢ ≡ 3 (mod 4), and that pᵢ is a prime divisor of N. ∎

Proof of Theorem 1. Suppose, for contradiction, that only finitely many primes are congruent to 3 modulo 4. Then we can list them all: q₁, q₂, …, q_k with each qᵢ ≡ 3 (mod 4), and every prime ≡ 3 (mod 4) appearing in the list. (The list is nonempty, since 3 itself is such a prime; the argument below also handles the empty-list case by taking the empty product to equal 1.)

Consider the integer

M = 4·q₁q₂⋯q_k − 1.

We check three properties.

  1. M ≡ 3 (mod 4). Indeed M = 4·(q₁⋯q_k) − 1 and 4·(q₁⋯q_k) ≡ 0 (mod 4), so M ≡ −1 ≡ 3 (mod 4), using (F1).
  2. M > 1. If k ≥ 1, then q₁⋯q_k ≥ 3, so M ≥ 4·3 − 1 = 11 > 1. If k = 0, then M = 3 > 1.
  3. M shares no prime factor with q₁⋯q_k. If some qᵢ divided M, then since qᵢ clearly divides 4·q₁⋯q_k, property (F2) of divisibility would give qᵢ | (4·q₁⋯q_k − M) = 1, impossible by (F2) since qᵢ ≥ 3.

By properties 1 and 2 and Lemma 1.2, M has a prime divisor p with p ≡ 3 (mod 4). By properties 1–2, M ≥ 3, so Lemma 1.2 applies. But every prime congruent to 3 mod 4 is one of the qᵢ, by our completeness assumption; so p = qᵢ for some i, contradicting property 3.

The contradiction shows that the assumption "finitely many" is false. Hence there are infinitely many primes congruent to 3 modulo 4. ∎

Remark. The specific form M = 4·q₁⋯q_k − 1 was needed to force M ≡ 3 (mod 4) while remaining coprime to all the qᵢ. The number 4·q₁⋯q_k + 1 is ≡ 1 (mod 4), and Lemma 1.2 gives no information about such numbers, which is why the naive variant fails.

Theorem 2. The number √2 + √3 is irrational.

The strategy: show that x = √2 + √3 is a root of the monic polynomial f(T) = T⁴ − 10T² + 1 with integer coefficients, and then show f has no rational root. A rational x would be a rational root of f, which is impossible.

Lemma 2.1. If a, b are integers with gcd(a, b) = 1 and k ≥ 1, then gcd(aᵏ, b) = 1.*

Proof. Suppose a prime p divides aᵏ. By uniqueness of prime factorization (F3), the only primes dividing aᵏ are the primes dividing a (the factorization of aᵏ is that of a written k times). Hence p | a, so p divides both a and b, contradicting gcd(a,b) = 1. Therefore no prime divides both aᵏ and b, i.e. gcd(aᵏ, b) = 1. ∎

Lemma 2.2 (Rational Root Test, monic case). Let f(T) = Tᵈ + c_{d−1}T^{d−1} + ⋯ + c₁T + c₀ be a polynomial with integer coefficients, c₀ ≠ 0. If the rational number a/b, written in lowest terms with b > 0 (so gcd(a,b) = 1), is a root of f, then b = 1 and a divides c₀.

Proof. Assume f(a/b) = 0. Multiply the equation (a/b)ᵈ + c_{d−1}(a/b)^{d−1} + ⋯ + c₁(a/b) + c₀ = 0 by bᵈ:

aᵈ + c_{d−1}a^{d−1}b + c_{d−2}a^{d−2}b² + ⋯ + c₁ab^{d−1} + c₀bᵈ = 0.   (∗)

(This is legitimate: each term cⱼ(a/b)ʲ · bᵈ = cⱼ aʲ b^{d−j} is an integer.)

Isolate aᵈ in (∗): every term except c₀bᵈ contains a factor b, so

aᵈ = −b·(c_{d−1}a^{d−1} + c_{d−2}a^{d−2}b + ⋯ + c₁ab^{d−2} + c₀b^{d−1}),

and the parenthesis is an integer. Hence b | aᵈ. By Lemma 2.1, gcd(aᵈ, b) = 1. A divisor of aᵈ that is coprime to aᵈ must divide 1 in absolute value; formally, any prime dividing b would divide aᵈ, and Lemma 2.1 shows there is none, so b has no prime divisors, whence b = 1 (b > 0 by convention, and b ≠ 0 as b is a denominator).

With b = 1, (∗) becomes aᵈ + c_{d−1}a^{d−1} + ⋯ + c₁a + c₀ = 0, so

c₀ = −a·(a^{d−1} + c_{d−1}a^{d−2} + ⋯ + c₁),

and the parenthesis is an integer; hence a | c₀. ∎

Lemma 2.3. The number x = √2 + √3 satisfies x⁴ − 10x² + 1 = 0.

Proof. We compute in several justified steps.

  1. x² = (√2 + √3)² = (√2)² + 2·√2·√3 + (√3)², by expanding (a+b)² = a² + 2ab + b², which itself follows from distributivity: (a+b)² = (a+b)(a+b) = a·a + a·b + b·a + b·b.
  2. (√2)² = 2 and (√3)² = 3 by the defining property (F6) of square roots, and √2·√3 = √6 by (F6). Hence x² = 2 + 2√6 + 3 = 5 + 2√6.
  3. Therefore x² − 5 = 2√6 (subtract 5 from both sides).
  4. Squaring both sides of a true equality gives a true equality, so (x² − 5)² = (2√6)² = 4·6 = 24.
  5. Expanding the left side, (x² − 5)² = x⁴ − 10x² + 25. Hence x⁴ − 10x² + 25 = 24, and subtracting 24 from both sides gives x⁴ − 10x² + 1 = 0. ∎

Proof of Theorem 2. By Lemma 2.3, x = √2 + √3 is a root of f(T) = T⁴ − 10T² + 1, a monic polynomial in Z[T] with constant term c₀ = 1 ≠ 0.

Suppose for contradiction that x is rational; write x = a/b in lowest terms with b > 0. By Lemma 2.2, b = 1 and a | 1, so a ∈ {1, −1} and x ∈ {1, −1}.

However, x is positive and in fact x > 2: since 2 > 1 and 3 > 1, (F6) gives √2 > √1 = 1 and √3 > 1, hence x = √2 + √3 > 1 + 1 = 2. (Concretely, f(1) = 1 − 10 + 1 = −8 ≠ 0 and f(−1) = 1 − 10 + 1 = −8 ≠ 0, confirming directly that neither candidate is a root.) But no number x > 2 lies in {1, −1}. This contradiction shows x is not rational. ∎

Theorem 3. Every finite tournament has a Hamiltonian path.

Definitions. A tournament on a finite nonempty vertex set V is an orientation of the complete graph on V: for every pair of distinct vertices {u, v}, exactly one of the directed edges u → v or v → u is present (and not both, and not neither). A Hamiltonian path is a listing of all vertices, each exactly once, say v₁, v₂, …, vₙ (so (v₁, …, vₙ) is a permutation of V), such that vᵢ → vᵢ₊₁ is a directed edge for every i = 1, …, n−1.

We prove, by induction on n = |V| (using (F5)), the statement S(n): "every tournament on n vertices has a Hamiltonian path."

Base case, n = 1. A single vertex v₁ forms, by itself, a path containing every vertex exactly once: the required condition "vᵢ → vᵢ₊₁ for all i = 1, …, n−1" ranges over the empty index set and is therefore satisfied vacuously.

Induction step. Assume S(n−1) for some n ≥ 2. Let T be a tournament on n vertices. Choose any vertex v of T and let V' = V ∖ {v}. The directed edges of T between vertices of V' make V' into a tournament: for every pair {u, w} ⊆ V', the edge between u and w in T has exactly one direction, and it is retained in the restriction. This restricted tournament has n − 1 vertices, so by the induction hypothesis S(n−1), it has a Hamiltonian path; write it as

v₁ → v₂ → ⋯ → v_{n−1},

meaning each vᵢ → vᵢ₊₁ is an edge of T (the edges between V' vertices in T and in the restriction coincide), and (v₁, …, v_{n−1}) lists every vertex of V' exactly once.

We insert the removed vertex v into this list. Exactly one of the edges between v and v₁ is present in T, so either v → v₁ or v₁ → v; likewise, either v_{n−1} → v or v → v_{n−1}. Three cases exhaust all possibilities:

  • Case 1: v → v₁. Then v → v₁ → v₂ → ⋯ → v_{n−1} is a Hamiltonian path of T: the new first edge v → v₁ holds by assumption, all other consecutive edges are edges of the old path, and the list contains v once and every vertex of V' once, hence all n vertices once.
  • Case 2: v_{n−1} → v. Then v₁ → ⋯ → v_{n−1} → v is a Hamiltonian path, by the symmetric verification.

  • Case 3: neither of the above. Then v₁ → v (since exactly one of v → v₁, v₁ → v holds and Case 1 failed) and v → v_{n−1} (likewise, Case 2 failed). Note this case requires n ≥ 3, since for n = 2 the conditions "v₁ → v" and "v → v₁" are the two complementary Cases 1 and 2. Define the index set

    S = { i ∈ {1, …, n−1} : vᵢ → v }.

We have 1 ∈ S (shown above), so S is nonempty, and n−1 ∉ S because v → v_{n−1} means the edge v_{n−1} → v is not present. By (F4), S has a largest element; call it i. Since n−1 ∉ S, we have i ≤ n−2, so the index i+1 ≤ n−1 is valid, and the edge between v and vᵢ₊₁ exists in exactly one direction. By maximality of i in S, we have i+1 ∉ S, which says vᵢ₊₁ → v is not an edge; therefore the other direction, v → vᵢ₊₁, is an edge. Now form the list

  v₁ → ⋯ → vᵢ → v → vᵢ₊₁ → ⋯ → v_{n−1}.

Check the consecutive edges: for j < i the pairs (vⱼ, vⱼ₊₁) are consecutive pairs of the old path, hence edges; the pair (vᵢ, v) is an edge because i ∈ S; the pair (v, vᵢ₊₁) is an edge because v → vᵢ₊₁ as just shown; and for j ≥ i+1 the pairs (vⱼ, vⱼ₊₁) are again consecutive pairs of the old path. The list is a permutation of V: it contains v₁, …, vᵢ, then v (which is distinct from all vⱼ since v ∉ V'), then vᵢ₊₁, …, v_{n−1}, each exactly once. Hence it is a Hamiltonian path.

In every case T has a Hamiltonian path, so S(n) holds. By (F5), S(n) holds for every n ≥ 1, i.e. every finite tournament has a Hamiltonian path. ∎

Theorem 4. For every integer n ≥ 1, 1³ + 3³ + ⋯ + (2n−1)³ = n²(2n² − 1).

Write S(n) for the statement: Σ_{k=1}^{n} (2k−1)³ = n²(2n² − 1). We prove ∀n ≥ 1, S(n) by induction, using (F5).

Base case, n = 1. The left side is the single term (2·1−1)³ = 1³ = 1. The right side is 1²·(2·1² − 1) = 1·(2 − 1) = 1·1 = 1. The two sides agree, so S(1) holds.

Induction step. Fix n ≥ 1 and assume S(n):

Σ_{k=1}^{n} (2k−1)³ = n²(2n² − 1).   (induction hypothesis)

Consider the left side for n+1. Separating off the last term (valid because the sum over k = 1, …, n+1 is the sum over k = 1, …, n plus the k = n+1 term):

Σ_{k=1}^{n+1} (2k−1)³ = n²(2n² − 1) + (2n+1)³,

where we applied the induction hypothesis to the first n terms and noted that 2(n+1) − 1 = 2n + 1. Now expand both pieces into a polynomial in n.

  • n²(2n² − 1) = 2n⁴ − n² (distributivity).
  • (2n+1)³ = (2n)³ + 3(2n)²·1 + 3·(2n)·1² + 1³ = 8n³ + 12n² + 6n + 1, using the binomial expansion (a+b)³ = a³ + 3a²b + 3ab² + b³ (itself obtained by repeated distributivity) with a = 2n, b = 1.

Adding and collecting like powers of n:

2n⁴ − n² + 8n³ + 12n² + 6n + 1 = 2n⁴ + 8n³ + 11n² + 6n + 1,

where the n²-coefficients combine as −1 + 12 = 11.

Next, expand the right side of S(n+1), namely (n+1)²·(2(n+1)² − 1):

  • (n+1)² = n² + 2n + 1.
  • 2(n+1)² − 1 = 2(n² + 2n + 1) − 1 = 2n² + 4n + 1.

Multiplying, distributing the second factor across the terms of the first:

(n² + 2n + 1)(2n² + 4n + 1)
  = n²(2n² + 4n + 1) + 2n(2n² + 4n + 1) + 1·(2n² + 4n + 1)
  = (2n⁴ + 4n³ + n²) + (4n³ + 8n² + 2n) + (2n² + 4n + 1)
  = 2n⁴ + 8n³ + 11n² + 6n + 1,

collecting: n³-coefficients 4 + 4 = 8; n²-coefficients 1 + 8 + 2 = 11; n-coefficients 2 + 4 = 6; constant 1.

The right side of S(n+1) and the left side of S(n+1) both equal 2n⁴ + 8n³ + 11n² + 6n + 1, so they are equal to each other; hence S(n+1) holds.

By (F5), S(n) holds for all integers n ≥ 1. ∎
