Ambiguous or contradictory points

  • Hypercorn docs location: the canonical docs site https://pgjones.gitlab.io/hypercorn/ could not be fetched (GitLab Pages auth redirect + Cloudflare challenge, HTTP 403). The values above come from the readthedocs mirror of the same official Sphinx docs ("Hypercorn 0.17.3 documentation", © Philip Jones).
  • Hypercorn graceful_timeout default: the configuration table row is truncated in both the rendered page and the page's own .rst source ("Time to wait after SIGTERM or Ctrl-C for any remaining requests (tasks) to") and the Default cell is empty, so the default is not documented. (The separate shutdown_timeout = 60s applies only to Lifespan shutdowns, not request draining.)
  • Uvicorn --timeout-graceful-shutdown default: the settings page lists the flag but states no default value, so it is reported as "not documented".
  • Uvicorn has no worker timeout at all: --timeout-worker-healthcheck (5 s) is the closest documented equivalent; it is a multiprocess healthcheck, not a request timeout.
  • Hypercorn has no worker timeout: --read-timeout (default "No timeout.") is the closest documented socket-level timeout.
  • Gunicorn defaults are environment-dependent: bind becomes 0.0.0.0:$PORT if PORT is set, and workers become $WEB_CONCURRENCY if set. Uvicorn's workers likewise follow $WEB_CONCURRENCY.
  • Gunicorn keep-alive caveat: the same settings page notes "sync worker does not support persistent connections and will ignore this option", so the 2 s default does not apply to the default worker class.
  • Gunicorn HTTP/2 is new/beta: the settings page marks HTTP/2 settings "Added in 25.0.0" and the guide calls it a beta feature; older Gunicorn documentation did not describe native HTTP/2 at all, so sources predating 25.0.0 will contradict this table.
  • Uvicorn HTTP/2 implementation changed: the current docs require the experimental zttp parser (--http zttp --http2); the --http options list (auto, h11, httptools, zttp) does not itself enable HTTP/2.
