Proofs

Four proofs, written step by step. Standard facts we are allowed to use are stated explicitly as lemmas or remarks so that every deduction can be checked.

Conventions. a | b means "a divides b", i.e. there exists an integer c with b = ac. Congruences are modulo 4 unless stated otherwise. A "prime" is a positive prime.

1. Infinitely many primes congruent to 3 (mod 4)

We use two standard facts, stated for reference.

Fact 1 (Fundamental Theorem of Arithmetic). Every integer N > 1 can be written as a product of primes, and this factorization is unique up to ordering.

Fact 2 (Divisibility is preserved under subtraction). If q | A and q | B, then q | (A − B). Reason: A = qm and B = qn for integers m, n, so A − B = q(m − n).

Lemma 1.1. The product of any finite collection of integers each congruent to 1 (mod 4) is itself congruent to 1 (mod 4).

Proof of the lemma. It suffices to prove the claim for two factors, since the general case then follows by induction on the number of factors. If x = 4a + 1 and y = 4b + 1, then xy = (4a + 1)(4b + 1) = 16ab + 4a + 4b + 1 = 4(4ab + a + b) + 1, which is 1 more than a multiple of 4, i.e. xy ≡ 1 (mod 4). ∎

Proof of the theorem (by contradiction). Suppose, for contradiction, that only finitely many primes are congruent to 3 (mod 4). List them as q₁ = 3 < q₂ < ⋯ < q_k. (There is at least one, namely 3, so k ≥ 1.)

Define N = 4·q₁q₂⋯q_k − 1.

We check four properties of N.

  1. N > 1. Since k ≥ 1 and q₁ = 3, we have N ≥ 4·3 − 1 = 11 > 1.

  2. N is odd. The product 4·q₁⋯q_k is a multiple of 4, hence even; subtracting 1 gives an odd number.

  3. N ≡ 3 (mod 4). N = 4·q₁⋯q_k − 1 ≡ 0 − 1 ≡ −1 ≡ 3 (mod 4).

  4. N has a prime divisor q with q ≡ 3 (mod 4). By Fact 1, N > 1 has a prime factorization. Every prime factor of N is odd, because N is odd by (2) (an even prime factor, namely 2, would make N even). Every odd prime is congruent to 1 or to 3 (mod 4), since an odd integer is not divisible by 2 and so its remainder mod 4 is 1 or 3. If every prime factor of N were ≡ 1 (mod 4), then by Lemma 1.1 the product N would be ≡ 1 (mod 4), contradicting (3). Hence at least one prime factor q of N satisfies q ≡ 3 (mod 4).

By our assumption, q is one of the listed primes, say q = q_j. Then q divides the product 4·q₁⋯q_k. And q divides N, by (4). By Fact 2, q divides (4·q₁⋯q_k) − N = 1. But no prime divides 1 (a prime q ≥ 2 cannot equal a divisor of 1, whose only positive divisors are 1). This is a contradiction.

Therefore the list q₁, …, q_k could not have been complete: there are infinitely many primes congruent to 3 (mod 4). ∎

2. Irrationality of √2 + √3

Fact 3 (Closure of ℚ). Sums, differences, products, and quotients (by a nonzero value) of rational numbers are rational. Reason: writing the numbers with common denominators, (a/b) ± (c/d) = (ad ± bc)/bd, (a/b)(c/d) = ac/bd, and (a/b)/(c/d) = ad/(bc) with all quantities integers and denominators nonzero.

Lemma 2.1. √3 is irrational.

Proof. Suppose √3 = a/b with integers a, b, b > 0, and a/b in lowest terms, i.e. gcd(a, b) = 1. Squaring: 3 = a²/b², so a² = 3b². Hence 3 | a².

We claim 3 | a. Indeed, by Fact 1, a has a unique prime factorization, so the exponent of the prime 3 in the factorization of a² is exactly twice its exponent in a, hence even. Since a² = 3b², the prime 3 occurs in a², so its exponent in a² is a positive even number, at least 2; therefore a itself contains at least one factor 3, i.e. 3 | a.

Write a = 3c. Substituting: 9c² = 3b², so b² = 3c². Repeating the same argument with the roles of a and b swapped gives 3 | b. But then 3 divides both a and b, contradicting gcd(a, b) = 1. Hence √3 is irrational. ∎

Proof of the theorem (by contradiction). Suppose r = √2 + √3 is rational.

  1. Then √2 = r − √3. Square both sides (legitimate since both sides are equal real numbers): 2 = (r − √3)² = r² − 2r√3 + 3.

  2. Rearranging (subtract r² + 3 from both sides, then multiply by −1): 2r√3 = r² + 1.

  3. We have r = √2 + √3 > 0, so r ≠ 0 and we may divide by 2r: √3 = (r² + 1)/(2r).

  4. Since r is rational by assumption, r² + 1 and 2r are rational by Fact 3, and 2r ≠ 0, so (r² + 1)/(2r) is rational by Fact 3. Step 3 then says √3 is rational, contradicting Lemma 2.1.

Hence √2 + √3 is irrational. ∎

3. Every finite tournament has a Hamiltonian path

Definitions. A tournament on a finite vertex set V assigns a direction to each edge of the complete graph: for every pair of distinct vertices u, v, exactly one of the directed edges u → v or v → u is present (exactly one, because the underlying graph is complete and each edge gets exactly one direction). A Hamiltonian path is a listing of all vertices v₁, v₂, …, v_n (each exactly once) such that v_i → v_{i+1} is a directed edge for every i = 1, …, n−1.

Proof by induction on n = |V|.

Base case n = 1. The single vertex, listed alone, is a Hamiltonian path (there are no consecutive pairs to check).

Inductive step. Assume n ≥ 2 and that every tournament on n vertices has a Hamiltonian path. Let T be a tournament on n + 1 vertices. Pick any vertex v. The tournament T − v obtained by deleting v (and its incident edges) has n vertices, so by the induction hypothesis it has a Hamiltonian path v₁ → v₂ → ⋯ → v_n. We will insert v into this list. Every edge between v and some v_i has exactly one direction, which lets us split into cases.

Case A: v → v₁. Then v → v₁ → v₂ → ⋯ → v_n is a Hamiltonian path of T: it lists all n + 1 vertices once, and every consecutive pair is a directed edge (the new pair v → v₁ by the case assumption, the others by the induction hypothesis).

Case B: v_n → v. Then v₁ → ⋯ → v_n → v is a Hamiltonian path, by the same check.

Case C: neither A nor B holds. Then v → v₁ is false, so the edge {v, v₁} must be directed v₁ → v; and v_n → v is false, so the edge {v, v_n} is directed v → v_n. Define the set S = { i ∈ {1, …, n} : v_i → v }. We have 1 ∈ S (since v₁ → v) and n ∉ S (since v → v_n), so S is a nonempty proper subset of {1, …, n}. A nonempty set of integers has a largest element; let i = max S. Since n ∉ S, we have i ≤ n−1, so i + 1 is a valid index. Because i + 1 > i = max S, we have i + 1 ∉ S, meaning v_{i+1} → v is false, so the edge is directed v → v_{i+1}. Now insert v between v_i and v_{i+1}: v₁ → ⋯ → v_i → v → v_{i+1} → ⋯ → v_n. Check the consecutive pairs: pairs entirely among the v's are directed edges by the induction hypothesis; v_i → v holds because i ∈ S; and v → v_{i+1} holds because i + 1 ∉ S. This lists all n + 1 vertices exactly once, so it is a Hamiltonian path.

The three cases cover every possibility (Case C is the negation of A and B), and each produces a Hamiltonian path. By induction, every finite tournament on any number of vertices has a Hamiltonian path. ∎

4. Sum of the first n odd cubes

Claim. For every integer n ≥ 1, 1³ + 3³ + ⋯ + (2n−1)³ = n²(2n² − 1).

Proof by induction on n.

Base case n = 1. The left side is 1³ = 1. The right side is 1²·(2·1² − 1) = 1·(2 − 1) = 1·1 = 1. Equal.

Inductive step. Assume n ≥ 1 and that the identity holds for n: 1³ + 3³ + ⋯ + (2n−1)³ = n²(2n² − 1) = 2n⁴ − n². (IH) Consider the sum for n + 1. Its last term is (2(n+1) − 1)³ = (2n + 1)³, so S(n+1) = [1³ + 3³ + ⋯ + (2n−1)³] + (2n + 1)³ = (2n⁴ − n²) + (2n + 1)³, where the second equality uses (IH).

Expand the cube using (x + y)³ = x³ + 3x²y + 3xy² + y³ with x = 2n, y = 1: (2n + 1)³ = (2n)³ + 3(2n)²·1 + 3(2n)·1² + 1³ = 8n³ + 12n² + 6n + 1.

Therefore S(n+1) = 2n⁴ − n² + 8n³ + 12n² + 6n + 1 = 2n⁴ + 8n³ + 11n² + 6n + 1, after collecting like powers of n (the n² terms: −1 + 12 = 11).

Now expand the claimed closed form at n + 1: (n+1)² (2(n+1)² − 1) = (n² + 2n + 1)(2(n² + 2n + 1) − 1) = (n² + 2n + 1)(2n² + 4n + 1). Distribute the first factor over the second: - n²·(2n² + 4n + 1) = 2n⁴ + 4n³ + n² - 2n·(2n² + 4n + 1) = 4n³ + 8n² + 2n - 1·(2n² + 4n + 1) = 2n² + 4n + 1 Summing and collecting like powers: n⁴: 2; n³: 4 + 4 = 8; n²: 1 + 8 + 2 = 11; n: 2 + 4 = 6; constant: 1. So (n+1)²(2(n+1)² − 1) = 2n⁴ + 8n³ + 11n² + 6n + 1.

This is exactly the polynomial obtained above for S(n+1), so S(n+1) = (n+1)²(2(n+1)² − 1), which is the claim for n + 1.

By the principle of mathematical induction, the identity holds for all n ≥ 1. ∎
